# Returns a list of all the available RDataset names present

Returns a list of all the available RDataset names present

## Usage

``` r
get_rdataset_names()
```

## Value

No return value, list of all the available RDataset

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::get_rdataset_names()
} # }
```
