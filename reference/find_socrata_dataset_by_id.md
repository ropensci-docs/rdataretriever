# Returns metadata for the following dataset id

Returns metadata for the following dataset id

## Usage

``` r
find_socrata_dataset_by_id(dataset_id)
```

## Arguments

- dataset_id:

  id of the dataset

## Value

No return value, shows metadata for the following `dataset id`

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::socrata_dataset_info()
} # }
```
