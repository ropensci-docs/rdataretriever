# Get citation of a script

Get citation of a script

## Usage

``` r
get_script_citation(dataset = NULL)
```

## Arguments

- dataset:

  dataset to obtain citation

## Value

No return value, gets citation of a script

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::get_script_citation(dataset = "")
} # }
```
