# Get scripts upstream

Get scripts upstream

## Usage

``` r
get_script_upstream(dataset, repo = "")
```

## Arguments

- dataset:

  name of the dataset

- repo:

  path to the repository

## Value

No return value, gets upstream scripts

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::get_script_upstream("iris")
} # }
```
