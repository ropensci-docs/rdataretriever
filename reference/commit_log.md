# See the log of committed dataset stored in provenance directory

See the log of committed dataset stored in provenance directory

## Usage

``` r
commit_log(dataset)
```

## Arguments

- dataset:

  name of the dataset stored in provenance directory

## Value

No return value, prints message after commit

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::commit_log("iris")
} # }
```
