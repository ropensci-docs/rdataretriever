# Reset the scripts or data(raw_data) directory or both

Reset the scripts or data(raw_data) directory or both

## Usage

``` r
reset(scope = "all")
```

## Arguments

- scope:

  All resets both scripst and data directory

## Value

No return value, resets the scripts and the data directory

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::reset("iris")
} # }
```
