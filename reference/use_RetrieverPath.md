# Setting path of retriever

Setting path of retriever

## Usage

``` r
use_RetrieverPath(path)
```

## Arguments

- path:

  location of retriever in the system

## Value

No return value, setting path of retriever

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::use_RetrieverPath("/home/<system_name>/anaconda2/envs/py27/bin/")
} # }
```
