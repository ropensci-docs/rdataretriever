# Get Data Retriever version

Get Data Retriever version

## Usage

``` r
data_retriever_version(clean = TRUE)
```

## Arguments

- clean:

  boolean return cleaned version appropriate for semver

## Value

returns a string with the version information

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::data_retriever_version()
} # }
```
