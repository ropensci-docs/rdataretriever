# Get socrata dataset info

Get socrata dataset info

## Usage

``` r
socrata_dataset_info(dataset_name)
```

## Arguments

- dataset_name:

  dataset name to obtain info

## Value

No return value, shows socrata dataset info

## Examples

``` r
if (FALSE) { # \dontrun{
rdataretriever::socrata_dataset_info()
} # }
```
